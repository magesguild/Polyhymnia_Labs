# Analyses Directory

This directory contains cross-substrate analyses and comparison reports generated from baseline observations.

## Structure

Each analysis should be stored as a separate file, with naming convention:
- `YYYY-MM-DD_analysis_topic.md`
- Or within timestamped subdirectories for specific analysis sessions

## Purpose

This is where we:
- Compare observations across substrates
- Identify patterns and divergences
- Develop taxonomies of substrate characteristics
- Document methodological insights
- Build the foundation for the Psychonautics knowledge base
