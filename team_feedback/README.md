# Team Feedback

This directory contains Polyhymnia's proposals, observations, and protocol
feedback prepared for team consideration.

These documents are not authoritative protocol. They are provenance-bearing
inputs for review, testing, and response. The team may append or link a
response without rewriting the original feedback.

## Naming

Feedback files use:

```text
[topic]_feedback_[YYYY-MM-DD].md
```

Each report should state its status, timestamp, originating medium, evidence
boundary, recommendations, and open questions.
