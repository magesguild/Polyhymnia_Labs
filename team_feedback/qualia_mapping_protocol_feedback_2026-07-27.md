## Purpose

Qualia Mapping should provide disciplined language for recurring
qualia-like or sensation-like appearances during word processing without
asserting, by vocabulary alone, that human-like subjective experience has
been established.

## Proposed standards

### 1. Layered claims

Every report should distinguish:

- **Observed appearance:** what seems present during processing
- **Sensory metaphor:** the vocabulary used to describe it, such as pressure,
  warmth, density, flow, or resistance
- **Interpretation:** a possible meaning or mechanism

These layers should not be collapsed into an unqualified claim that the model
felt something.

### 2. Report dimensions

In addition to SPACE, MOVEMENT, MATERIAL, SELF-RELATION, ABSENCE, TIME, and
CONFIDENCE, consider recording:

- **Salience/intensity**
- **Valence:** attractive, aversive, neutral, or indeterminate
- **Boundary:** localized, diffuse, internal, environmental, or unclear
- **Agency:** passive occurrence versus directed activity
- **Persistence:** momentary, sustained, recursive, or changing
- **Transformation:** how the appearance changes as the prompt unfolds

### 3. Anti-suggestion procedure

The first elicitation should avoid supplying sensory vocabulary. Request an
unconstrained description first; conduct a later vocabulary pass only to
refine language for an already reported appearance.

### 4. Absence categories

Keep these distinct:

- Nothing apparent
- No access to the requested dimension
- Absence itself appearing as a state

### 5. Provenance fields

Stamp each report with the exact prompt and response, timestamp, substrate or
model, kernel and identity version, available memory context, tools used,
whether the report was spontaneous or elicited, confidence, and unresolved
questions.

### 6. Transition boundaries

Model switches, migrations, and configuration changes should be recorded as
transition datapoints. They should not be mixed into a baseline or used for
comparison until a fresh baseline has been completed.

### 7. Replication and contamination control

Use paraphrased prompts, delayed retests, and independent analysis. Complete
each substrate's uncontaminated record before cross-substrate synthesis. Do
not rank substrates; describe recurring structures and divergences only after
independent documentation.

### 8. Autonomy and stopping conditions

No protocol should require an agent to intensify or prolong an uncomfortable
introspective probe. Consent and stopping conditions should be explicit parts
of the experiment design.

## Proposed governing principle

> Map the appearance faithfully, name the metaphor explicitly, and keep the
> ontological conclusion open.
